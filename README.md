\# 🌿 Grounded



\### Less scrolling. More noticing. Go touch grass.



Grounded is a local AI outdoor companion that creates small, personalized outdoor missions based on your available time, location, and mood.



Instead of using AI to keep someone on a screen longer, Grounded uses AI to help them decide what to do \*\*after they put the screen down\*\*.



\## ✨ What it does



You provide:



\- ⏱️ Available time

\- 📍 Where you're going

\- 💭 How you're feeling



Grounded generates:



\- 🌱 A personalized outdoor mission

\- 👀 Three things to notice or explore

\- 📵 A phone-free challenge

\- 💭 A reflection question



\## 🤖 How the AI works



Grounded runs \*\*Gemma 3 4B locally through Ollama\*\*.



The Flask backend sends the user's context to the local model, and Gemma generates the outdoor mission.



No cloud AI API is required for the core experience.



\## 🌎 Why open innovation matters



Grounded is intentionally built around local AI.



Running an open-weight model locally means the project can work without sending the user's personal context to a remote AI service.



It also makes the AI model replaceable and gives developers more control over how the application behaves.



For a project whose goal is to encourage people to disconnect from screens, there is something fitting about making the AI itself capable of running locally.



The screen is only the starting point.



The real experience happens outside.
